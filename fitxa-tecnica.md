# Fitxa tècnica: Instal·lació d'Ubuntu Server

## Objectiu

Instal·lar Ubuntu Server en una màquina virtual amb VirtualBox.

## Materials

* Ordinador
* VirtualBox
* ISO d'Ubuntu Server

## Procediment

1. Obrir VirtualBox.
2. Crear una màquina virtual.
3. Posar la ISO d'Ubuntu Server.
4. Configurar la RAM i el disc.
5. Configurar la xarxa.
6. Iniciar la màquina virtual.
7. Instal·lar Ubuntu Server.
8. Crear l'usuari i la contrasenya.
9. Reiniciar la màquina.
10. Iniciar sessió i actualitzar el sistema.

```bash
sudo apt update
```

## Comprovacions

* [ ] Ubuntu Server inicia correctament.
* [ ] Puc iniciar sessió.
* [ ] Tinc connexió a Internet.

## Incidències i solucions

Incidència                                            

- No hi ha Internet              
- No inicia la màquina  

Solució

- Revisar l'adaptador de xarxa.

- Revisar la configuració de VirtualBox.
